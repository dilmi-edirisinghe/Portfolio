# Dilmi Edirisinghe Portfolio

## Files
- index.html — portfolio page
- style.css — styling
- script.js — mobile navigation
- cv.pdf — CV linked from the portfolio

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Create a GitHub repository, upload all files in this folder, then enable GitHub Pages from
Settings → Pages → Deploy from branch → main → /(root).
